=== LICENSE NOTES ===

CC0 (Public Domain):
- No attribution required
- Can be used commercially
- Examples: FreePD.com tracks

CC-BY (Attribution):
- Attribution required (Artist name + Source link)
- Can be used commercially
- Examples: Bensound tracks

CC-BY-SA (Attribution + Share Alike):
- Attribution required
- Derivatives must use same license
- Examples: Some OpenGameArt tracks
