## 🎼 IMPLEMENTATION WITH HOWLER.JS

### **Audio Manager Setup**

```typescript
// src/core/AudioManager.ts
import { Howl, Howler } from 'howler';

interface AudioTrack {
	name: string;
	src: string;
	volume?: number;
	loop?: boolean;
}

class AudioManager {
	private music: Map<string, Howl> = new Map();
	private sfx: Map<string, Howl> = new Map();
	private currentMusic: Howl | null = null;

	constructor() {
		// Set global volume
		Howler.volume(0.7);
	}

	// Preload music for a chapter
	preloadChapterMusic(chapter: number) {
		const track = new Howl({
			src: [`/audio/music/chapters/ch${chapter}_theme.mp3`],
			volume: 0.6,
			loop: true,
			preload: true,
		});
		this.music.set(`chapter_${chapter}`, track);
	}

	// Play background music with crossfade
	playMusic(name: string, fadeTime: number = 2000) {
		const track = this.music.get(name);
		if (!track) return;

		// Fade out current music
		if (this.currentMusic) {
			this.currentMusic.fade(this.currentMusic.volume(), 0, fadeTime);
			setTimeout(() => {
				this.currentMusic?.stop();
			}, fadeTime);
		}

		// Fade in new music
		track.volume(0);
		track.play();
		track.fade(0, 0.6, fadeTime);
		this.currentMusic = track;
	}

	// Play sound effect
	playSFX(name: string) {
		let sound = this.sfx.get(name);

		if (!sound) {
			sound = new Howl({
				src: [`/audio/sfx/${name}.wav`],
				volume: 0.5,
			});
			this.sfx.set(name, sound);
		}

		sound.play();
	}

	// Toggle mute
	toggleMute() {
		Howler.mute(!Howler._muted);
	}

	// Set master volume
	setVolume(volume: number) {
		Howler.volume(volume);
	}
}

export const audioManager = new AudioManager();
```

### **Usage in Components**

```typescript
// In your game scene
import { audioManager } from '@/core/AudioManager';

// When entering chapter
audioManager.playMusic('chapter_1');

// When clicking button
audioManager.playSFX('ui/button_click');

// When stats change
audioManager.playSFX('stats/steel_mind_up');
```

## ⚠️ AUDIO OPTIMIZATION TIPS

### **File Format Recommendations**

```yaml
Music (Background):
  Format: OGG Vorbis (best for web)
  Bitrate: 128kbps (balance quality/size)
  Sample Rate: 44.1kHz

SFX (Short sounds):
  Format: WAV (no compression artifacts)
  Bitrate: 16-bit
  Sample Rate: 44.1kHz

Mobile Optimization:
  - Use lower bitrate (96kbps) for mobile builds
  - Mono instead of stereo where possible
  - Lazy load music per chapter
```

### **Performance Best Practices**

- ✅ Preload music for next chapter during gameplay
- ✅ Use audio sprites for UI sounds (combine multiple SFX)
- ✅ Implement audio fade for smooth transitions
- ✅ Add mute/volume controls in settings
- ✅ Pause music when app goes to background (mobile)
